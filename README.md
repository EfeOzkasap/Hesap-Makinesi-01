# 🧮 Modern Hesap Makinesi

Python ve CustomTkinter kullanılarak geliştirilmiş modern masaüstü hesap makinesi.

## ✨ Özellikler

- Modern ve karanlık arayüz
- Dört işlem desteği
- Yüzde hesaplama
- Klavye ile kullanım
- İşlem geçmişi
- İşlem geçmişini kalıcı kaydetme
- Geçmişteki işlemleri tekrar yükleme
- Özel uygulama ikonu
- Windows EXE desteği

## 🚀 Çalıştırma

### EXE sürümü
`HesapMakinesi.exe` dosyasını indirip çift tıklamanız yeterlidir.

### Python sürümü

Gerekli kütüphaneyi yükleyin:

```bash
python -m pip install customtkinter
```

Ardından:

```bash
python arayuz.py
```

- Python
- CustomTkinter
- JSON
